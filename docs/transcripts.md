# SecClaw pitch video transcript

`[00:00]` SecClaw is a local-first security operations agent built for enterprise I.T. and security teams.

`[00:08]` Security teams need speed, but sensitive infrastructure data should not leave the building, and autonomous remediation should never outrun authorization.

`[00:19]` SecClaw closes that gap with one controlled loop.

`[00:23]` It discovers authorized assets, explains evidence with a local model, asks a human to approve the exact plan, executes inside an OpenShell sandbox, and rescans to prove the result.

`[00:38]` The entire stack runs on the Dell Pro Max with GB10.

`[00:43]` The dashboard, evidence store, scanner, OpenShell sandbox, and GPT-OSS-120B inference service stay local.

`[00:51]` No cloud LLM calls are in the runtime path.

`[00:56]` In the demo, an administrator defines the allowed scope.

`[01:01]` SecClaw detects an exposed service, preserves the evidence, generates a grounded remediation plan, binds approval to a plan hash, applies the controlled action, and verifies the outcome with an automatic rescan.

`[01:14]` Requests outside the authorized scope are refused and audited.

`[01:19]` For lean I.T. teams, this means faster understanding, safer remediation, and a complete audit trail without giving the model unchecked authority.

`[01:26]` SecClaw watches the risk, while humans keep the authority.
